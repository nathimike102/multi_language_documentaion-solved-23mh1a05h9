# Introduction (Version 2)

Welcome to version 2 of the Documentation Portal! This version includes several improvements and new features.

## What's New in v2?

Version 2 brings exciting enhancements:

- **Improved performance** with better caching strategies
- **Enhanced search** with better relevance
- **New API endpoints** for extended functionality
- **Better mobile support** with responsive design
- **Accessibility improvements** for all users

## Migration from v1

If you're upgrading from v1, check our migration guide for detailed instructions.

### Breaking Changes

- API endpoint structure has changed
- Configuration format updated
- Some deprecated features removed

### New Features

1. **Advanced Search**: Full-text search with filters
2. **Real-time Updates**: Live documentation updates
3. **API Playground**: Test APIs directly in the docs
4. **Community Comments**: Discuss documentation with others

## Quick Start

```javascript
import { initializeApp } from "@example/sdk";

const app = initializeApp({
  apiKey: "your-api-key",
  version: "v2",
});
```
