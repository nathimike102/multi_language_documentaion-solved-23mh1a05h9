# Introducción (Versión 2)

¡Bienvenido a la versión 2 del Portal de Documentación! Esta versión incluye varias mejoras y nuevas características.

## ¿Qué hay de nuevo en v2?

La versión 2 trae mejoras emocionantes:

- **Rendimiento mejorado** con mejores estrategias de caché
- **Búsqueda mejorada** con mejor relevancia
- **Nuevos endpoints de API** para funcionalidad extendida
- **Mejor soporte móvil** con diseño responsive
- **Mejoras de accesibilidad** para todos los usuarios

## Migración desde v1

Si estás actualizando desde v1, consulta nuestra guía de migración para instrucciones detalladas.

### Cambios Importantes

- La estructura del endpoint de API ha cambiado
- Formato de configuración actualizado
- Algunas características obsoletas eliminadas

### Nuevas Características

1. **Búsqueda Avanzada**: Búsqueda de texto completo con filtros
2. **Actualizaciones en Tiempo Real**: Actualizaciones de documentación en vivo
3. **API Playground**: Prueba APIs directamente en los docs
4. **Comentarios de la Comunidad**: Discute la documentación con otros

## Inicio Rápido

```javascript
import { initializeApp } from "@example/sdk";

const app = initializeApp({
  apiKey: "tu-api-key",
  version: "v2",
});
```
