# Introduction (Version 2)

Bienvenue dans la version 2 du Portail de Documentation ! Cette version comprend plusieurs améliorations et nouvelles fonctionnalités.

## Quoi de neuf dans v2 ?

La version 2 apporte des améliorations passionnantes :

- **Performance améliorée** avec de meilleures stratégies de mise en cache
- **Recherche améliorée** avec une meilleure pertinence
- **Nouveaux endpoints API** pour des fonctionnalités étendues
- **Meilleur support mobile** avec un design responsive
- **Améliorations d'accessibilité** pour tous les utilisateurs

## Migration depuis v1

Si vous effectuez une mise à niveau depuis v1, consultez notre guide de migration pour des instructions détaillées.

## Démarrage Rapide

```javascript
import { initializeApp } from "@example/sdk";

const app = initializeApp({
  apiKey: "votre-api-key",
  version: "v2",
});
```
