# Einführung (Version 2)

Willkommen bei Version 2 des Dokumentationsportals! Diese Version enthält mehrere Verbesserungen und neue Funktionen.

## Was ist neu in v2?

Version 2 bringt aufregende Verbesserungen:

- **Verbesserte Leistung** mit besseren Caching-Strategien
- **Verbesserte Suche** mit besserer Relevanz
- **Neue API-Endpunkte** für erweiterte Funktionalität
- **Bessere mobile Unterstützung** mit responsivem Design
- **Barrierefreiheitsverbesserungen** für alle Benutzer

## Migration von v1

Wenn Sie von v1 upgraden, lesen Sie unseren Migrationsleitfaden für detaillierte Anweisungen.

## Schnellstart

```javascript
import { initializeApp } from "@example/sdk";

const app = initializeApp({
  apiKey: "ihr-api-key",
  version: "v2",
});
```
